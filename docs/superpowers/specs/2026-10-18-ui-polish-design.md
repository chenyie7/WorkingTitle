# UI 外壳打磨设计

日期：2026-10-18
状态：已与用户确认方向与三节细节，待实现

## 1. 背景

应用的外观伪装成 Microsoft Word。当前界面能看出「像 Word」，但细节不成立：

- 左侧章节栏是自定义阅读器侧栏（书名 + 章节 + 每行百分比），不是 Word 的任何部件；
- 功能区在 1280 宽下装不下「开始」页五个组，样式库被右边缘裁掉，字号下拉截成「初…」；
- 字号在 10 / 10.5 / 11 / 12 / 12.5 / 13 之间散落，控件高度有 26 / 28 / 30 / 32，图标从 12 到 24 混用；
- 设置与书库弹层每行标签前挂一个蓝色小图标，更像网页设置页，不像 Word 的「选项」对话框。

用户已确认：方向是「收拾工整、仍像 Word」，不是另起一套设计语言；浅色与深色一起改；允许调整 DOM 结构与功能区分组；主要痛点是左侧章节栏。

## 2. 目标与非目标

目标：

1. 左栏重做成 Word 的「导航窗格」：标题、可用的搜索框、书名/卷/章三级树、展开三角、当前章高亮。
2. 「开始」页在 1280 宽下不出现横向滚动；所有控件不截断，组标题落在同一条基线。
3. 建立一套字号、间距、控件高度、图标尺寸的 token，浅色与深色都由 token 推导。
4. 设置与书库弹层按 Word「选项」对话框的排法收口：无逐行装饰图标、统一控件高度、footer 有分隔线。

非目标：

- 不改阅读纸张的宽度、页边距、正文字体、行高与首行缩进。
- 不给功能区占位项接真实功能；「插入」页删掉的占位组不补回。
- 不做响应式折叠。最小窗口 940px 下功能区允许横向滚动。
- 不引入新依赖。

## 3. 设计 token

所有 token 写在 `src/renderer/src/styles/word.css` 的 `:root` 与 `[data-theme='dark']` 中。

### 3.1 字号

| token | 值 | 用途 |
| --- | --- | --- |
| `--wt-fs-xs` | 10.5px | 组标题、样式库名、章节百分比 |
| `--wt-fs-sm` | 11.5px | 大按钮标签、状态栏、元信息 |
| `--wt-fs-md` | 12.5px | 页签、控件、对话框行、章节标题 |
| `--wt-fs-lg` | 13.5px | 对话框标题 |

正文仍为 13px（`body`），不并入四档。

### 3.2 间距

统一用 2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 / 24。2px 只用于同一行内的微调，其余走 4 的倍数。

### 3.3 控件高度

| 值 | 用途 |
| --- | --- |
| 26px | 功能区小按钮、下拉框、分割按钮主体与箭头 |
| 28px | 导航窗格树行、搜索框 |
| 30px | 对话框输入框、按钮、分段控件、快捷键框 |
| 54px | 功能区主体（两行 26 + 2 间距），大按钮同高 |

### 3.4 图标

| 值 | 用途 |
| --- | --- |
| 12px | 展开三角、下拉箭头、树折叠箭头 |
| 14px | 搜索框放大镜、导航栏页签图标 |
| 16px | 功能区小按钮 |
| 20px | 功能区大按钮、对话框标题图标 |

### 3.5 颜色

保留现有品牌蓝 `#185abd` 与 Word 中性阶。新增一个语义色：

- `--wt-hover`：浅色 `#f2f3f5`，深色 `#26262d`，用于树行与列表行的悬停。

复用既有 token，不新增重复值：

- 选中底用 `--wt-blue-light`（浅色 `#eaf1fb`，深色 `#2b2b34`）；
- 分隔线用 `--wt-chrome-border`；
- 主按钮用 `--wt-primary` / `--wt-primary-hover`。

`ribbon.css`、`page.css` 里写死的 `#edf2fa`、`#f2f3f5`、`#e8e8ea`、`#999999` 全部换成 token。

### 3.6 圆角与动效

- 圆角保持 4px（控件）与 6px（面板、大块）。
- 交互过渡保持 90ms ease，不新增动效。

## 4. 导航窗格

### 4.1 结构

```
导航                                  ×
[ 搜索章节                          ]
诡秘之主（整理版）                  ▾
    第一卷 起势                     ▾
        第一章 绯红                 39%
        第二章 情况
    第二卷 承接                     ▸
```

- 面板宽 240px，与现有 `.wt-sidebar` 一致。
- 面板头高 36px：左「导航」12.5px/600，右关闭按钮 24×24（图标 12px），title 仍带收起快捷键。
- 搜索框高 28px，左右内缩 10px，底部留 8px；放大镜 14px；占位文字「搜索章节」；有内容时右侧显示清除按钮。
- 树行高 28px，缩进为 `10 + 层数 × 14`。
- 书名行与卷行 12.5px/600，章节行 12.5px/400。
- 有子项的行左侧留 16px 箭头槽，箭头 12px；章节行不占箭头槽。
- 书名作为树的根（第 0 层），卷为第 1 层，卷下章节为第 2 层；没有卷时章节直接为第 1 层。
- 行尾百分比 10.5px、`--wt-text-muted`、`tabular-nums`、右对齐。
- 当前章：整行 `--wt-blue-light` 底、600 字重，`aria-current="true"`。
- 悬停：整行 `--wt-hover`。
- 空态：没有小说时隐藏搜索框，显示「未导入小说」与「文件 → 设置 → 导入小说」。

### 4.2 百分比显示规则

- 当前章始终显示百分比，包括 `0%`。
- 非当前章只在 `pct > 0` 时显示，未读章节留白。
- 书名行与卷行不显示百分比。
- 计算沿用现有逻辑：`chapterPos` 缺项按 0，进度超过 `charCount` 时封顶 100。

### 4.3 搜索

- 输入即过滤，不区分大小写的子串匹配，匹配对象只有章节标题。
- 书名行始终显示；卷行只在它的某个子章节命中时作为父节点显示；命中的章节全部显示。
- 搜索结果里的卷显示为展开，但**不改动**用户的收起状态；清空查询后恢复原来的展开/收起。
- 没有命中时列表区显示一行「没有匹配的章节」。
- `Esc` 清空搜索，`Enter` 跳到第一条命中的章节。
- 每次查询变化后滚动位置回到顶部。
- 点击结果跳章后保留查询，不自动清空。

### 4.4 展开与收起

- 书名行与卷行默认展开。
- 点击箭头只切换展开状态，不触发跳转；点击行标题仍调用 `onJump`。
- 收起状态只存在组件内存里，不落盘，与现有行为一致。
- 打字推进时把当前章滚进视野；如果它所在的卷被用户手动收起，不强行展开。

### 4.5 虚拟滚动

- 保留现有虚拟滚动，但按展平后的树行计算。
- `ROW_HEIGHT` 从 32 改为 28。
- 滚动容器、overscan（6 行）、视口兜底（400px）的机制不变。
- 搜索或展开状态变化时，按新的行数组重算可视窗口。

### 4.6 无障碍与焦点

- 列表容器 `role="tree"`，行 `role="treeitem"`，可展开行带 `aria-expanded`。
- 搜索框是 `<input>`，本来就在焦点豁免名单里，点击它不会打断输入法。
- 点击树行后由现有的 window 点击处理器把焦点抢回正文 textarea。
- 收起后的细缝从 12px 改为 10px，背景透明，箭头只在悬停时显形；快捷键提示不删。

## 5. 功能区

### 5.1 尺寸与排布

- 功能区最小高度 84px（原 92px），内边距 `4px 8px 3px`。窄窗口出现横向滚动条时高度允许随之增长，组标题不得被裁掉。
- 每组左右内边距 8px，组间分隔线只贯穿 54px 主体，不落到组标题上。
- 组内仍是两行按列填充：`grid-template-rows: 26px 26px`，间距 2px。
- 组主体固定 54px；大按钮同高，宽 58px，图标 20px、标签 11.5px。
- 组标签用 `--wt-fs-xs`，贴底对齐；因为所有组主体等高，标签自然落在同一条基线。
- 小按钮 26×26，图标 16px；图标类按钮只显示图标，标签仍用视觉隐藏保留给读屏。

### 5.2 下拉框

- 字体框宽 144px，字号框宽 64px，行距框宽 58px。
- 所有下拉框高 26px，字号 12.5px，文字左内边距 9px、右内边距 5px，箭头 12px。
- 字号框 64px 能完整显示「初号」「小初」，「Times New Roman」不会出现在字号里，字体框 144px 能完整显示「Times New Roman」。

### 5.3 样式库

- 可见 4 项，宽 56px，预览 `AaBbCc` 13px、名称 10.5px。
- 可见项取前 4 个；如果当前样式不在这 4 个里，用当前样式替换第 4 个，保证选中态始终可见。
- 右侧一个 22px 宽的展开按钮，点开 portal 面板列出全部 7 个样式，面板视觉复用 `.wt-combo__panel`。
- 当前样式不在前 4 个时，展开按钮进入选中态，避免「看不出选了哪个」。

### 5.4 「插入」页收组

「插入」页从 29 个大按钮收到 18 个，保证 1280 宽下不横向滚动：

| 组 | 保留项 |
| --- | --- |
| 页面 | 封面、空白页、分页 |
| 表格 | 表格 |
| 插图 | 图片、形状、图标、图表 |
| 链接 | 链接 |
| 页眉和页脚 | 页眉、页脚、页码 |
| 文本 | 文本框、艺术字、首字下沉、日期和时间 |
| 符号 | 公式、符号 |

删除的项与组：3D 模型、SmartArt、屏幕截图、书签、交叉引用、签名行、对象，以及「加载项」「媒体」「批注」三组。它们都是占位，不影响任何真实功能。

### 5.5 其余页

- 文件、布局、引用、审阅、视图五页只统一尺寸，不删项。
- 按上述尺寸计算，最宽的是审阅页，约 1268px，仍在 1280 内。
- 最小窗口 940px 下允许横向滚动，不加滚动提示。

## 6. 设置与书库弹层

### 6.1 排法

- 去掉 `.wt-modal__label` 前的蓝色小图标，只留文字；导航栏图标保留并统一 14px、`--wt-text-muted`。
- 行标签列固定 92px，字号 12.5px，颜色 `--wt-text-muted`。
- 行距 16px，内容区左右内边距 20px。
- 输入框、普通按钮、主按钮、分段控件、快捷键框统一 30px 高；比例输入框宽 64px。
- footer 高 48px，顶部一条 1px `--wt-chrome-border` 分隔线，内容右对齐，左右内边距 20px。
- 面板宽度 680px 不变；高度从 410px 改为 424px。424px 是「阅读设置」页 6 行在 30px 控件下的自然高度加上标题条与 footer，换页时面板仍纹丝不动。实现完成后再在真机核一次，若最高页超过 424px，按实测值上调。

### 6.2 书库页

- 列表行高 44px，名称 12.5px，元信息 11.5px。
- 当前书用 `--wt-blue-light` 底 + 3px 左缘 `--wt-accent`，不再用整圈蓝边框。
- 删除按钮仍用 `--wt-danger` 文字，不改成实心红按钮。

## 7. 状态栏与标题条

- 状态栏高 24px（原 26px），字号 11.5px，间距 16px（原 18px），左右内边距 12px。
- 状态栏内容与现有语义不变，章节位置保持 `2 / 1382` 的形状。
- 标题条高 32px 不变，字号 12.5px；文档名与 `Word` 的层级保持现状（应用名 600、文档名 400）。

## 10. 风险与已知取舍

- **特异度**：`ribbon.css` 里 `.wt-btn:not(...)` 那条高特异度规则会吃掉按钮背景，新增尺寸规则时保持现有排除名单，不改成裸 `.wt-btn`。
- **高度联动**：`ROW_HEIGHT` 同时被组件、虚拟滚动与测试使用，改 28 必须三处同步；CLAUDE.md 里提到的「行高常量与样式一致」这条判据保留。
- **固定面板高度**：424px 若与最高页不符，会重新出现换页上下跳；实现后必须真机量一次。
- **删占位项**：插入页删掉的项没有真实功能，删除不会影响行为；但 `Ribbon.tsx` 里有注释说明这些项是为密度补的，实现时同步删掉相应注释。
- **深色**：新增 `--wt-hover` 与所有尺寸改动都要在深色下截图核验；颜色只走 token，不写死。
- **百分比**：只显示当前章与已读章，会让「哪些章读过」比现在更含蓄；这是为了像 Word 的导航窗格，已与用户确认保留信息但降低噪音。
