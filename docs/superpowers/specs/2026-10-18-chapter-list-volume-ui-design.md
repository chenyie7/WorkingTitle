# 章节列表的卷分组（UI）设计

日期：2026-10-18
状态：已实现（2026-10-18）

## 1. 目标

带卷的小说在侧栏里是平铺的：「第一卷 起势」和「第1章 开端」长得一样，
分组关系看不出来。本次把卷标题渲染成分组头，卷下的章节缩进一档，让目录结构一眼可见。

只改侧栏的显示，不动章节数据、不动切章规则、不动阅读进度。

## 2. 卷标题的判定

放在 `src/core/chapters.ts`：

```ts
export function isVolumeTitle(title: string): boolean
```

- 按 trim 后的整行匹配，长度上限沿用 `MAX_TITLE_LEN`。
- 覆盖三类写法：
  - `第X卷/部/篇/集`（可带副标题），如「第一卷 起势」「第 12 篇」；
  - `卷X`，如「卷一 起势」；
  - `上/中/下 部篇卷`，如「上 部 楔子」。
- 与 `ChapterRule` 无关：切章时它可能被任何规则识别出来，分组只看标题本身。
- 误判的代价只是缩进或加粗一档，不影响正文与进度，所以判定从宽。

## 3. 渲染

`ChapterList` 一次遍历章节，算出两个布尔数组：

- `volume[i]`：这一行是不是卷标题；
- `grouped[i]`：不是卷标题、且前面已经出现过卷标题。

行高仍是 `ROW_HEIGHT`（32px），虚拟滚动的窗口计算不变。

- 卷标题行：`chapter-item--volume`，通栏浅灰底 + 左侧 3px 竖条 + 加粗；不显示百分比
  （卷标题这一项本身只有标题行，百分比没有意义）。
- 卷下章节：`chapter-item--grouped`，左内边距 22px。
- 第一个卷之前的内容（如「前言」）不算卷下，不缩进。
- 卷标题行仍可点击跳转；当前章节落在卷标题上时，选中态优先于分组样式。
- 深色外观单独给一套底色与竖条颜色。

## 4. 不做的事

- 不做折叠/展开：卷头点击仍是跳转，不持有额外状态。
- 不做滚动吸顶：虚拟列表是绝对定位，吸顶要另算一套布局。
- 不持久化任何分组状态。
- 不改变 `Chapter` 结构与切章结果，卷标题仍是普通章节项。

## 5. 测试

- `tests/unit/chapters.test.ts`：三类卷标题的正例、章节/前言/无分隔符样本的反例。
- `tests/unit/chapterList.test.tsx`：卷头带 `chapter-item--volume` 且无百分比、卷下章节带
  `chapter-item--grouped`、第一个卷之前不缩进、卷头可点击跳转。
